# 业务默认值与待确认项

依据原 V1.0 方案；以下默认值用于继续开发，不代表业务负责人已确认。

| 项目 | 可先采用的默认值 | 需要提供/确认 |
|---|---|---|
| 人员和团队 | 四角色、按团队隔离 | 运营/咨询/主管名单、所属团队；不需要提供密码 |
| 字典 | 不硬编码真实业务清单 | 首批病种、渠道、区域、院区、无效/转派原因 |
| 分配 | 权重1、容量30/日、默认离线 | 每位咨询病种能力、权重、容量、排班；30仅开发默认 |
| 时限 | 接收5分钟、首联15分钟 | 回收阈值、回访与沉默时间；超时阻断规则 |
| 重复 | 团队内全历史匹配，主管复核，保留原运营 | 重复窗口、跨团队处理、再次咨询与归属口径 |
| 运营结果权限 | 可看进度和个人汇总，不看备注/单条金额 | 是否允许单条金额、汇总金额 |
| 经营核验 | 成交金额整数分，仅核验金额纳入收入 | 有效客资、到院核验、退款、提成和成本口径 |
| 消息 | 仅站内 | 是否已有企业微信/SCRM；第二阶段接口资料 |
| 部署 | 单机本地开发 | 正式部署环境、数据库选择、保存期限和备份要求 |

当前不接现有服务器、不替换 zx.njyymkj.com、不迁移患者数据。先完成可测业务闭环，再评估旧系统迁移。提成、AI客服、平台自动抓取、收费系统对接为扩展模块，未纳入当前实现。
